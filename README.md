# Sistem Perbandingan Vendor IT

Aplikasi PHP Native + MySQL untuk perencanaan anggaran vendor IT di PT Angkasa Pura Aviasi.

## Persiapan
1. Jalankan XAMPP Control Panel.
2. Start Apache dan MySQL.
3. Buka browser ke http://localhost/pemograman%20web/install.php
4. Ikuti proses instalasi sampai selesai.
5. Login dengan:
   - admin / admin123
   - manager / manager123

## Jalankan aplikasi
- URL utama: http://localhost/pemograman%20web/login.php

## Struktur utama
- config/database.php
- includes/auth.php
- dashboard.php
- vendor.php
- install.php

## Catatan
- Database default: vendor_budget
- Username DB: root
- Password DB: kosong
